Pre-training & post-training a GNN when labels are scarce

Five self-supervised objectives learn from the citation graph without labels. The encoders are then fine-tuned with as few as one label per class, and a post-training stack of self-training, Correct & Smooth, ensembling, calibration and distillation runs on top. Every selection uses the validation set. The test set is only read for reporting.
