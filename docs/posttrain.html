The model keeps learning after training ends.

The pretrained encoder has been fine-tuned on a handful of labelled papers, and the training labels are spent. Post-training keeps going without them. A calibrated teacher labels the papers it is most sure about, students learn from those pseudo-labels, and the students join the teacher. The validation set decides when to stop, and the test set is never consulted.

06 · keeping score honestly

How the test set stayed clean

  • Validation picks everythingRounds, Correct & Smooth α values, ensemble members, temperature and the distillation weight are all chosen on the 500 validation papers.
  • Validation is never pseudo-labelledPseudo-labels come only from papers outside the labelled and validation sets, so the selection signal stays independent.
  • Designed on validation onlyThe loop's design (students, rounds, consistency) was compared with a script that prints validation accuracy and nothing else.
  • Five seeds, fresh labelsEach seed draws a new set of labelled papers and pre-trains new encoders. Every number is mean ± std over all five.
